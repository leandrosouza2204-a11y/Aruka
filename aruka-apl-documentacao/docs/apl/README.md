# Aruka Performance Library (APL)

> Biblioteca oficial de modelos de treinamento da Aruka.

**Versão:** 1.0.0  
**Status:** Em desenvolvimento

## Propósito

A APL oferece modelos de treinamento organizados e tecnicamente justificáveis para servirem como ponto de partida da prescrição profissional. Ela não substitui avaliação, individualização ou acompanhamento.

> A APL não é uma coleção de listas de exercícios. É uma biblioteca de estratégias de treinamento.

## Organização

```text
Objetivo → Público de referência → Nível → Divisão → Estratégia → Modelo
```

Divisões da v1.0: ABC, ABCD, ABCDE, Full Body e Upper/Lower.

Estratégias: Base, Performance, Eficiência e Especialização.

## Módulos

- **APL:** modelos de treino.
- **AOE:** catálogo mestre de exercícios e equivalências.
- **AEP:** protocolos técnicos de execução.

## Processo

```text
Construção → Revisão técnica → QA metodológico → Revisão documental → Homologação → Publicação
```

## Versionamento

A biblioteca utiliza `MAJOR.MINOR.PATCH`.
