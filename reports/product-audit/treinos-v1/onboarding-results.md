# Onboarding Results

O usuario entende que pode criar um treino porque o CTA esta visivel. Ainda assim, o produto nao explica o fluxo mental:

- Treino: ficha atribuida a um aluno.
- Modelo: base reutilizavel para gerar uma ficha editavel.
- Exercicio: item dentro de um dia de treino.

Para usuario novo, o estado vazio deveria guiar para "Criar treino para este aluno" ou "Comecar por modelo". Hoje ele informa e oferece acoes, mas nao contextualiza o aluno nem reduz duvida.
