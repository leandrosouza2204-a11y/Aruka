# Cutover Backup Checklist

- [ ] projeto de produção confirmado como aruka
- [ ] project ref conferido visualmente no Dashboard
- [ ] janela de manutenção definida
- [ ] método de backup escolhido
- [ ] backup gerenciado localizado ou criado
- [ ] timestamp do backup registrado
- [ ] referência do backup registrada
- [ ] retenção suficiente confirmada
- [ ] método de restore revisado
- [ ] responsável pela verificação identificado
- [ ] backup lógico adicional avaliado
- [ ] Storage avaliado separadamente
- [ ] nenhum cutover iniciado
- [ ] backup aprovado para uso como recovery point
