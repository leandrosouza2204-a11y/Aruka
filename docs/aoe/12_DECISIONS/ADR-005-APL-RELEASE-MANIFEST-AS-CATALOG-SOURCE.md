# ADR-005 - APL Release Manifest as Catalog Source

## Status

Accepted.

## Decisao

O catalogo ativo do AOE sera construido a partir de releases oficiais congeladas, manifests e modelos validados por checksum.

## Consequencias

- Maior auditabilidade.
- Dependencia da qualidade dos manifests.
- Necessidade de validacao formal.
- Fixtures deixam de ser fonte oficial.
