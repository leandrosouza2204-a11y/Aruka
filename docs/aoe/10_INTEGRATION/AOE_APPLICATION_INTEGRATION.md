## Requisitos

- Motor sem dependência de React.
- Motor sem dependência de Supabase.
- Domínio isolado.
- Entrada e saída serializáveis.
- Uso futuro em API, Edge Function ou backend Node.
- Logs sem dados pessoais desnecessários.

Endpoint final não é definido nesta fase.
