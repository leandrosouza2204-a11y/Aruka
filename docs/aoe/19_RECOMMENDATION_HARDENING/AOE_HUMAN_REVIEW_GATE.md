# AOE Human Review Gate

O gate retorna:

- `required`
- `blocking`
- `status`
- `reasonCodes`
- `reasons`
- `checklist`
- `suggestedActions`

O gate nao pode ser desligado globalmente. Especializacao, risco alto, dados ausentes, empate tecnico, adaptacao de equipamento e conflitos criticos acionam revisao.
