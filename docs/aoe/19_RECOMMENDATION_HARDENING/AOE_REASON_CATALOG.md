# AOE Reason Catalog

O catalogo centraliza reason codes com categoria, severidade, descricao tecnica, descricao para usuario, acao padrao e flags de bloqueio/revisao.

Validacoes:

- Codigos unicos.
- Descricoes presentes.
- Flags booleanas.
- Cobertura dos reason codes do dominio.

Comando:

```bash
npm run aoe:reasons
```
