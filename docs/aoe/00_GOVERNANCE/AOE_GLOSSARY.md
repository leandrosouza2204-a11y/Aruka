# AOE Glossary

| Termo | Definição |
|---|---|
| APL | Aruka Performance Library, base homologada de modelos. |
| AOE | Aruka Optimization Engine, motor de decisão. |
| AQA | Aruka Quality Assurance, auditoria documental automatizada. |
| Modelo | Prescrição APL homologada com código e versão. |
| Candidato | Modelo elegível para avaliação. |
| Elegibilidade | Condição mínima para entrar no conjunto de candidatos. |
| Exclusão | Remoção por incompatibilidade crítica. |
| Restrição | Condição que limita ou impede recomendação. |
| Preferência | Sinal não crítico informado pelo aluno ou profissional. |
| Score | Pontuação de compatibilidade do candidato. |
| Peso | Importância relativa de uma dimensão de score. |
| Ranking | Ordenação determinística dos candidatos. |
| Seleção | Escolha final após ranking e validação. |
| Desempate | Política usada quando scores equivalentes competem. |
| Fallback | Resultado seguro quando seleção automática não é possível. |
| Confiança | Medida autônoma em relação ao score sobre qualidade da decisão. |
| Recomendação | Resultado final validado ou sinalizado para revisão. |
| Decisão | Conjunto de seleção, motivos, versões e evidências. |
| Decision trace | Rastro estruturado de decisão. |
| Customização | Ajuste futuro de modelo selecionado. |
| Progressão | Evolução futura de carga, volume ou modelo. |
| Revisão humana | Avaliação profissional antes da entrega. |
| Regra crítica | Regra que pode impedir recomendação. |
| Regra não crítica | Regra que gera score, warning ou confiança. |
| Hard constraint | Restrição que exclui candidato. |
| Soft constraint | Restrição que reduz score ou confiança. |
| Baseline | Release usada como referência comparativa. |
