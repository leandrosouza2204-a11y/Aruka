# AOE Public Input Contract

`AOEDecisionRequestV1` usa `contractVersion: "1.0.0"`, `requestId`, `idempotencyKey`, `actor`, `student`, `options` e `metadata`.

Campos livres são limitados, funções são recusadas e dados médicos livres não são aceitos como condição para executar o motor.

Papéis públicos: `PROFESSIONAL`, `ADMIN`, `SYSTEM`, `STUDENT_READ_ONLY`.
