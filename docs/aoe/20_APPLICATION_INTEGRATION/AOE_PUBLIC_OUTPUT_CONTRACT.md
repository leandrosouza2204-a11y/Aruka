# AOE Public Output Contract

`AOEDecisionResponseV1` expõe apenas a resposta necessária para a aplicação:

- status público;
- modelo selecionado;
- alternativas limitadas;
- scores;
- classificação de confiança, risco e ambiguidade;
- explicação resumida;
- estado de revisão humana;
- versões.

Decision trace completo não é exposto por padrão.
