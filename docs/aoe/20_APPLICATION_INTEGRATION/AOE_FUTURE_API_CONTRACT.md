# AOE Future API Contract

Recursos futuros, sem implementação HTTP nesta versão:

- `POST /aoe/decisions`
- `GET /aoe/decisions/{decisionId}`
- `GET /aoe/decisions/{decisionId}/trace`
- `POST /aoe/reviews`
- `GET /aoe/reviews/{reviewId}`
- `GET /aoe/health`

Headers de idempotência e autenticação serão definidos em ciclo posterior.
