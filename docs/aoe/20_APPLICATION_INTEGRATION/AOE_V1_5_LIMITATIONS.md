# AOE v1.5 Limitations

- Não existe banco real.
- Não existe API HTTP.
- Não existe autenticação real.
- Não existe UI.
- Repositórios são em memória.
- Revisão humana não altera treinos.
- Customização não existe.
- Progressão não existe.
- Retenção precisa de validação jurídica.
- Status HTTP são conceituais.
- Observabilidade não está conectada a fornecedor externo.
