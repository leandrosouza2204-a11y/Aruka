# AOE Privacy And Redaction

O AOE minimiza dados em logs, auditoria, persistência e resposta pública.

Proibido em logs:

- nome;
- e-mail;
- telefone;
- endereço;
- observação livre integral;
- dados médicos livres;
- perfil completo.

Reason codes, status e dados técnicos mínimos são preservados.
