# AOE Catalog Integrity

Invariantes validadas:

- `modelCode` unico.
- Modelo homologado.
- Release ativa.
- Checksum valido.
- Versao presente.
- Nivel valido.
- Objetivo valido.
- Divisao valida.
- Estrategia valida.
- Frequencia valida.
- Duracao valida.
- Status valido.
- Campos criticos presentes.

Warnings nao criticos sao mantidos para lacunas documentais que nao impedem decisao.
