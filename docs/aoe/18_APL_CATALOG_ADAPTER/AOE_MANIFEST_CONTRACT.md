# AOE Manifest Contract

O adapter reconhece tabelas Markdown de identidade, inventario e checksums.

Campos minimos por modelo:

- Codigo.
- Bloco.
- Arquivo.
- Estrategia.
- Status.
- SHA-256.

Os caminhos podem ser relativos ao projeto ou relativos ao manifesto. A saida publica preserva caminhos relativos ao projeto.
