# AOE Release Discovery

Uma release candidata precisa conter:

- `README.md`
- `*_FREEZE.md`
- `*_RELEASE_NOTES.md`
- `*_CHANGELOG.md`
- `*_MANIFEST.md`

Uma release ativa precisa estar homologada e congelada, possuir manifesto valido, modelos existentes, checksums validos e nenhuma inconsistencia critica.

Releases atuais:

- `SPRINT_01@1.0.0`
- `SPRINT_02@2.0.0`
