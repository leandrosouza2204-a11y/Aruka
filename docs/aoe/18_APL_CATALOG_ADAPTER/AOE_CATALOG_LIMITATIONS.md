# AOE Catalog Limitations

Limitacoes conhecidas:

- O adapter nao altera a APL.
- O adapter nao corrige manifests.
- O adapter nao infere essencialidade de equipamento a partir de todas as prescricoes.
- Alguns modelos nao diferenciam equipamentos essenciais e adaptaveis; isso gera warning.
- O engine nao le Markdown diretamente.
- Nao ha banco, API, UI, customizacao ou progressao automatica nesta etapa.
