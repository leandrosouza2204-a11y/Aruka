# AOE Model Metadata Mapping

O parser le cabecalho, tabela `Metadados`, tags e titulo.

Mapeamentos principais:

| Origem | Destino |
|---|---|
| Masculino | `MALE` |
| Feminino | `FEMALE` |
| Iniciante | `BEGINNER` |
| Intermediario | `INTERMEDIATE` |
| Hipertrofia | `HYPERTROPHY` |
| Full Body | `FULL_BODY` |
| Upper/Lower | `UPPER_LOWER` |
| Base | `BASE` |
| Performance | `PERFORMANCE` |
| Eficiencia | `EFFICIENCY` |
| Especializacao | `SPECIALIZATION` |

Especializacoes:

- `ESP-PEITO` -> `PEITORAL`
- `ESP-DELTS` -> `DELTOIDES`
- `ESP-COSTAS` -> `COSTAS`
