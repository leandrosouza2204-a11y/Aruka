# AOE Dimension Scores

## Goal Fit

| Score | Critério |
|---:|---|
| 100 | Objetivo exatamente compatível. |
| 0 | Objetivo incompatível. |

Objetivo incompatível deve ser exclusão antes do score.

## Level Fit

| Score | Critério |
|---:|---|
| 100 | Nível exato. |
| 70 | Modelo imediatamente abaixo, apenas se política futura permitir. |
| 0 | Modelo acima do nível. |

Na v1, modelo acima do nível é inelegível.

## Frequency Fit

| Score | Critério |
|---:|---|
| 100 | Frequência exata. |
| 80 | Aluno possui um dia adicional. |
| 60 | Aluno possui mais disponibilidade que o necessário, sem prejuízo. |
| 0 | Frequência insuficiente. |

## Duration Fit

| Score | Critério |
|---:|---|
| 100 | Tempo disponível com margem confortável. |
| 80 | Compatível com margem pequena. |
| 60 | Compatível no limite. |
| 0 | Tempo insuficiente. |

## Equipment Fit

| Score | Critério |
|---:|---|
| 100 | Todos os equipamentos disponíveis. |
| 80 | Pequenas substituições futuras necessárias. |
| 50 | Múltiplas adaptações. |
| 0 | Equipamento essencial ausente e sem adaptação homologada. |

## Recovery Fit

| Score | Critério |
|---:|---|
| 100 | Capacidade acima da demanda. |
| 80 | Capacidade compatível. |
| 60 | Capacidade no limite. |
| 0 | Demanda acima da capacidade. |

## Adherence Fit

| Score | Critério |
|---:|---|
| 100 | Rotina e histórico compatíveis. |
| 80 | Compatível com risco pequeno. |
| 60 | Risco moderado. |
| 0 | Demanda incompatível. |

## Preference Fit

| Score | Critério |
|---:|---|
| 100 | Preferência exata. |
| 70 | Neutro. |
| 40 | Preferência diferente, sem incompatibilidade. |

Preferência nunca gera exclusão sozinha.
