# AOE Scoring Specification

## Finalidade

Esta área define o scoring documental do AOE v1.1: dimensões, pesos, normalização, penalizações e exemplos.

## Documentos

- `AOE_SCORING_SPEC_V1.md`: fórmula oficial.
- `AOE_DIMENSION_SCORES.md`: escala por dimensão.
- `AOE_WEIGHT_CALIBRATION.md`: pesos v1 e calibração futura.
- `AOE_PENALTY_MODEL.md`: penalizações não críticas.
- `AOE_SCORE_EXAMPLES.md`: exemplos de cálculo.

## Dependências

Depende do catálogo de regras v1.0.0 e do princípio de que eligibility e exclusion ocorrem antes do score.

## Versão

Scoring Specification v1.0.0.

## Implementação futura

O AOE v1.2 deverá implementar estes cálculos com testes automatizados e decision trace.
