# AOE Recommendation Validation

## Validações após seleção

- Modelo existe.
- Release está homologada.
- Nível compatível.
- Objetivo compatível.
- Frequência compatível.
- Duração compatível.
- Equipamentos compatíveis.
- Nenhuma exclusão crítica.
- Score válido.
- Decision trace completo.
- Confidence calculado.

Falha de validação impede entrega automática.
