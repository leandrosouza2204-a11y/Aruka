# AOE Customization Boundaries

## O AOE v1 pode

- Selecionar modelo.
- Sugerir necessidade de adaptação.
- Indicar incompatibilidades.

## O AOE v1 não pode

- Trocar exercícios automaticamente.
- Alterar séries.
- Alterar volume.
- Alterar métodos.
- Mudar frequência.
- Remover sessão.
- Criar modelo híbrido.

Essas funções pertencem ao AOE v2.0.
