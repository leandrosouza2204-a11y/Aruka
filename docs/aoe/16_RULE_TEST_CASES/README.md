# AOE Rule Test Cases

## Finalidade

Esta área documenta casos de teste conceituais para o catálogo de regras, scoring, confidence e revisão humana.

## Documentos

- `AOE_RULE_TEST_CASES_V1.md`: 100 casos por categoria.
- `AOE_GOLDEN_SCENARIOS.md`: 15 cenários completos.
- `AOE_REGRESSION_MATRIX.md`: matriz de regressão.

## Dependências

Depende do Rule Catalog v1.0.0 e da Scoring Specification v1.0.0.

## Versão

Rule Test Cases v1.0.0.

## Implementação futura

O AOE v1.2 deverá transformar estes casos em testes automatizados.
