# AOE Tiebreakers

## Ordem inicial

1. Menor número de warnings.
2. Maior aderência estimada.
3. Menor complexidade compatível.
4. Menor demanda de recuperação.
5. Menor necessidade de equipamentos.
6. Menor duração compatível.
7. Estratégia Base antes de Performance quando ainda houver incerteza.
8. Código do modelo em ordem alfabética como último critério determinístico.

O último critério não possui valor metodológico; serve apenas para determinismo.
