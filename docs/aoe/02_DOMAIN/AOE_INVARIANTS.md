# AOE Invariants

- Um modelo excluído não pode ser selecionado.
- Um candidato inelegível não recebe score final.
- Score deve ficar em faixa definida.
- Toda seleção deve possuir decision trace.
- Toda exclusão deve possuir motivo.
- Todo resultado deve registrar versões.
- Empate deve ser resolvido por política explícita.
- Ausência de candidato deve retornar resultado formal.
- Baixa confiança deve exigir revisão humana.
- Regras críticas prevalecem sobre preferências.
- Scoring não pode compensar restrição crítica.
- Modelo selecionado deve existir na APL homologada.
- Versão do modelo deve ser registrada.
- Entrada inválida não entra no pipeline decisório.
