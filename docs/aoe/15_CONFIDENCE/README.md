# AOE Confidence

## Finalidade

Esta área define o Confidence Score do AOE v1.1, separado do Compatibility Score.

## Documentos

- `AOE_CONFIDENCE_MODEL.md`: fórmula e faixas.
- `AOE_DATA_COMPLETENESS.md`: campos críticos, importantes e opcionais.
- `AOE_HUMAN_REVIEW_THRESHOLDS.md`: gatilhos de revisão humana.

## Dependências

Depende do pipeline, das regras de confidence e da validação de recomendação.

## Versão

Confidence Model v1.0.0.

## Relação com implementação futura

O AOE v1.2 deverá calcular confidence como dimensão autônoma do resultado.
