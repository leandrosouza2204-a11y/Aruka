# AOE Eligibility Rules

## Propósito

Regras de elegibilidade verificam requisitos mínimos antes de qualquer score.

## Dimensões

- Sexo.
- Objetivo.
- Nível.
- Frequência disponível.
- Duração disponível.
- Equipamentos.
- Divisão compatível.
- Capacidade de recuperação.
- Experiência mínima.
- Aderência necessária.
- Disponibilidade para especialização.

## Exemplos

- Aluno intermediário pode ser elegível para Sprint 02.
- Aluno iniciante não é elegível para modelo intermediário.
- Aluno com 3 dias não é elegível para ABCDE.
- Aluno com 40 minutos pode ser inelegível para modelo de 70 minutos.
- Equipamento inexistente pode excluir modelo quando não houver adaptação homologada.

Pesos definitivos pertencem ao ciclo v1.1.
