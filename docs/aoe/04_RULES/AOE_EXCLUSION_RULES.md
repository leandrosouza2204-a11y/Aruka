# AOE Exclusion Rules

## Hard constraints iniciais

- Objetivo incompatível.
- Nível incompatível.
- Frequência insuficiente.
- Tempo incompatível.
- Equipamento essencial ausente.
- Restrição impeditiva.
- Modelo não homologado.
- Versão congelada indisponível.
- Especialização sem critérios mínimos.
- Recuperação insuficiente para a divisão.

## Hard exclusion

Remove o candidato e exige ExclusionReason.

## Soft warning

Mantém candidato com penalização, redução de confiança ou revisão humana.

## Regra central

Score nunca compensa hard exclusion.
