# AOE Rule Catalog

## Finalidade

Esta área formaliza o catálogo documental de regras do AOE v1.1. Ela transforma os conceitos do AOE v1.0 em regras versionadas, identificáveis e preparadas para teste.

## Documentos

- `AOE_RULE_CATALOG_V1.md`: catálogo oficial com regras v1.
- `AOE_RULE_ID_STANDARD.md`: padrão permanente de IDs.
- `AOE_RULE_DEPENDENCIES.md`: dependências e precedência.
- `AOE_RULE_COVERAGE_MATRIX.md`: cobertura por dimensão e análise dos 30 modelos APL.

## Dependências

- AOE Architecture v1.
- APL Sprint 01 v1.0.0.
- APL Sprint 02 v2.0.0.

## Versão

Rule Catalog v1.0.0.

## Relação com implementação futura

Este catálogo será a fonte documental para implementação do AOE v1.2. Nenhuma regra executável é criada nesta etapa.
