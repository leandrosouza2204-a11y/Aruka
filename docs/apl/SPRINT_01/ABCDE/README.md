# Sprint 01 - ABCDE Masculino Iniciante

Este diretorio contem os modelos ABCDE da Sprint 01 da Aruka Performance Library (APL), voltados ao publico masculino iniciante em hipertrofia. A divisao ABCDE separa o treino em cinco sessoes curtas, aumentando a frequencia de pratica sem transformar cada dia em uma sessao volumosa.

Status do bloco ABCDE: **Em desenvolvimento**.

## Publico-alvo

Iniciantes que conseguem treinar cinco vezes por semana, precisam aprender execucao e se beneficiam de sessoes curtas, previsiveis e com baixa fadiga.

## Vantagens

- Mais pratica semanal.
- Menor fadiga por sessao.
- Mais foco tecnico em cada grupamento.
- Melhor aderencia para quem prefere treinos curtos.
- Distribuicao simples do volume.

## Comparacao

| Criterio | Base | Performance | Eficiencia |
|----------|------|-------------|------------|
| Tempo | 45-55 min | 50-60 min | 35-45 min |
| Complexidade | Baixa | Media | Baixa |
| Frequencia | 5x | 5x | 5x |
| Exercicios Livres | Poucos | Moderados | Poucos |
| Tecnicas Avancadas | Nao | Top Set | Nao |
| Objetivo | Aprendizagem | Evolucao | Aderencia |
