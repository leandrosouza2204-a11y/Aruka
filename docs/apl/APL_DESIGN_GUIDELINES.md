# APL — Design Guidelines

## Estrutura obrigatória de cada modelo

1. Código interno
2. Nome comercial
3. Objetivo
4. Filosofia
5. Perfil indicado
6. Perfil não indicado
7. Estrutura semanal
8. Prescrição
9. Referência ao AOE
10. Engenharia
11. Assinatura Técnica

## Código interno

```text
APL-{PUBLICO}-{OBJETIVO}-{NIVEL}-{DIVISAO}-{ESTRATEGIA}-{NUMERO}
```

Exemplo: `APL-M-HIP-I-ABC-BASE-01`.

## Linguagem

Usar linguagem objetiva, técnica, profissional e simples. Evitar expressões sensacionalistas.
