# APL — Engenharia dos Modelos

## Fluxo de construção

```text
Problema → Estratégia → Público → Estrutura semanal → Frequência → Volume → Exercícios → Prescrição → Revisão → Homologação
```

## DNA da APL

Todo modelo deve possuir estratégia, identidade, progressão, escalabilidade e padronização.

## Base
Equilíbrio, aprendizagem, aplicabilidade e menor complexidade.

## Performance
Maior demanda técnica, pesos livres, coordenação e força básica.

## Eficiência
Redução de redundâncias e maior estímulo por minuto.

## Especialização
Prioridade para um grupamento, com controle do volume global.

## Critérios para um exercício permanecer

1. Contribui para a estratégia?
2. É compatível com o nível?
3. Possui boa relação estímulo/fadiga?
4. Possui alternativa no AOE?
5. Sua presença é justificável?

## Regra de identidade

Se dois modelos resolvem o mesmo problema e diferem apenas nos exercícios, um deles deve ser removido ou reformulado.
