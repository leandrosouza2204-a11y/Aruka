## Relação com a Sprint 01

A Sprint 01 é a baseline oficial do nível iniciante. A Sprint 02 representa a progressão para o nível intermediário, com evolução técnica validada em autonomia, volume recuperável, exercícios livres, métodos seletivos e especializações. A Sprint 02 não substitui a Sprint 01; ela amplia a biblioteca para outro nível de aluno.

## Política de manutenção

Qualquer alteração futura deve passar pelo AQA, ser registrada no changelog, preservar histórico, respeitar versionamento semântico e exigir revalidação humana quando tecnicamente relevante.
