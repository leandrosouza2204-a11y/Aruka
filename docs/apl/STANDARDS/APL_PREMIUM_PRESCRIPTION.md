# Padrão Oficial de Prescrição Premium

Este documento define a tabela oficial de exercícios da Aruka Performance Library. O formato deve ser usado em todos os modelos reais para que o AQA reconheça a prescrição sem tratamento especial.

## Tabela oficial

| Ordem | Exercício | Séries | Repetições | RIR | Descanso | Método | Observações |
|---:|---|:---:|:---:|:---:|:---:|---|---|

Os nomes das colunas devem ser exatamente:

- Ordem
- Exercício
- Séries
- Repetições
- RIR
- Descanso
- Método
- Observações

## Nomes não permitidos como substitutos

Não usar:

- Reps
- Intervalo
- Técnica
- Nota
- Volume
- Set
- Sets

## Regras das tabelas de prescrição

- Usar uma linha por exercício.
- Não mesclar séries e repetições em uma única coluna.
- Expressar descanso sempre em segundos ou faixa.
- Informar RIR de forma explícita.
- Preencher sempre o campo Método.
- Utilizar `Tradicional` quando não houver método especial.
- Não usar Observações para substituir campos obrigatórios.
- Usar duração em `Repetições` para exercícios isométricos.
- Indicar `por lado` ou `por perna` em exercícios unilaterais.
- Descrever Top Set e Back-off de forma inequívoca.
- Identificar superséries com `A1/A2`, `B1/B2` ou equivalente.
- Não criar tabelas de resumo com o mesmo formato de prescrição.

| Ordem | Exercício | Séries | Repetições | RIR | Descanso | Método | Observações |

## Tabelas não auditáveis como prescrição

As tabelas abaixo não são tabelas de prescrição:

- metadados;
- estrutura semanal;
- volume semanal;
- Aruka Score;
- comparação entre modelos;
- progressão;
- distribuição dos padrões de movimento.

Recomenda-se usar títulos imediatamente antes dessas tabelas para facilitar o parser:

### Tabela de metadados

### Volume direto estimado

### Aruka Score

## Compatibilidade com o AQA

O AQA deve encontrar as colunas oficiais literalmente. Se uma tabela de exercícios omitir coluna, trocar nome de coluna ou fundir campos, o documento deve ser corrigido antes de homologação.
