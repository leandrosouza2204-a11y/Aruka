# AOE — Aruka Exercise Equivalence

## Objetivo

Centralizar o catálogo mestre de exercícios e suas equivalências.

## Responsabilidades

Nome oficial, padrão de movimento, músculos, equipamento, complexidade, estabilidade, alternativas e justificativas.

## Níveis de equivalência

- A: alta equivalência.
- B: equivalência moderada.
- C: adaptação.
- D: contingência.

## Estrutura conceitual

```yaml
exerciseId:
officialName:
movementPattern:
primaryMuscle:
secondaryMuscles:
equipment:
exerciseType:
technicalLevel:
stability:
laterality:
plane:
alternativesA:
alternativesB:
alternativesC:
alternativesD:
notes:
status:
```

## Regra

Equivalência não deve ser confundida com substituição clínica automática.
